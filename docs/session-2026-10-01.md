## 修复

1. **CgMLP 深度卷积加速从未启用**（`model_tifa.cpp`）：
   `set_direct_dwconv` 只在 breath 模块里被调用过，TIFA 主模型一直跑 im2col
   慢路径。补上按后端能力的门控后（与 game.cpp 相同），**CPU 2.96 s → 0.67 s
   （4.4×）**，Vulkan ~12%。
2. **LSTM 图输入与 gallocr 竞技场重叠**：`in_h` 与 `out_logits` 被分配到同一
   偏移，解码第二步读到被覆盖的状态。图输入现在独占 backend buffer
   （与权重同款处理），在 `lstm_g2p.cpp` 的 `GraphRun::allocate_inputs`。
3. **`merge_breath_into_phones` 的间隙判定**：空区间不再算作"已覆盖"，跨越
   音素边界的呼吸丢弃而不是硬插；呼吸类标签 100 ms 内相邻合并。
4. **`read_textgrid_tier` 固定偏移解析**：`text = "..."`（等号前有空格）被读成
   `= "..."`，所有音素都解析失败。改为按 `=` 位置解析。
5. **发布包词典布局**（潜伏 bug）：GGUF 里的 `@dictionaries/x`、`@assets/LstmG2p-Eng`
   相对模型目录解析，而旧包把 `dicts/*` 平铺进 `models/`、且完全没带英文 LSTM
   模型——任何下载的包里 G2P 都会失败。现按
   `models/{tifa.gguf, dictionaries/, cpp_pinyin/, assets/}` 布局并在本地验证。
6. **UI 层两个致命 bug**：顶层 `const bridge` 与 contextBridge 的不可配置全局
   属性冲突（整页脚本 SyntaxError）；`item.outDir` 上轮运行的缓存覆盖新一轮
   输出目录（2PASS 阶段拿着旧目录去找第一遍产物）。
7. **误提交的 `scripts/__pycache__`**（10 个 .pyc，来自 `git add -A`）删除并加入
   `.gitignore`。
